Solution architecture

From the furnace meter to the operator's screen

On the furnace

Signals

  • Panel energy meter: kW, kWh (Modbus TCP)
  • Lid limit switch (digital input)
  • Operator app: charge, mix, dips, tap

In the foundry

Edge gateway

  • Polls meter: one snapshot per read
  • SQLite outbox: nothing lost offline
  • Forwards in order when online

MeltWise API (FastAPI)

Models

  • Energy model: physics + ML
  • Soft sensor + live advisor
  • Scheduler (ToD tariff, moulds)
  • Carbon record (CEA factor)

For people

Web app

  • Operator: live prompts (en, hi, ta)
  • Manager: kWh/t, causes, savings
  • Planner: melt schedule
  • Buyer: per-batch CO₂, CSV

Test harness (stands in for a plant until the pilot): a physics-based furnace simulator plays melts through a simulated Modbus meter at 40× speed. Re-running each melt with one practice gap removed gives the ground truth for every kWh of waste.

Schneider Electric fit: the gateway reads any Modbus meter, so EM6400NG or PowerLogic meters plug in by setting register addresses. Data can feed EcoStruxure or AVEVA.
