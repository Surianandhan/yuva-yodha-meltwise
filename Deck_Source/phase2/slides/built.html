What we built

Six working parts, one pipeline

Edge gateway

Reads the furnace meter over Modbus TCP; buffers every reading in SQLite and forwards when the network is up.

Energy model

Physics terms recalibrated on the plant's own melts, plus gradient boosting on the charge mix. Explains every kWh by cause.

Live operator advisor

Bath-temperature soft sensor and six prompt types, in English, Hindi and Tamil, while the metal is still in the furnace.

Melt scheduler

Starts each heat so metal is ready when the moulds are, priced on the time-of-day tariff.

Manager dashboard

kWh per tonne by day and melt, avoidable kWh by cause, savings in rupees and CO₂.

Buyer carbon record

Scope 2 CO₂ for every batch from metered energy, CEA grid factor, CSV export.

Running code: Python 3.13 · NumPy · scikit-learn · FastAPI · SQLite · pymodbus · Chart.js. 14 automated tests. Source: the team's GitHub repository.
