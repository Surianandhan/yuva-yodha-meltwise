Data flows left to right. On the furnace: the existing panel meter over Modbus, an optional lid switch and thermocouple, and the operator app. In the foundry: an edge gateway that keeps working when the internet drops, splits each melt into phases and runs the melt model locally, so prompts never wait for the cloud. In the cloud: the physics-plus-ML model is trained per furnace, a cause finder explains excess energy, an optimiser schedules melts, and a measurement-and-verification engine turns kWh into rupees and CO2. Everything is open standards, so it fits Schneider Electric meters and software.
