These numbers come from our impact model, which you can rerun. The baseline is a typical MSME foundry: one 1-tonne furnace, 2,400 tonnes a year at 650 kWh per tonne, 8 rupees per kWh. Each saving is tied to a shop-floor practice and a physics loss rate. The conservative case, 16.7 kWh per tonne, is below the 20 kWh per tonne BEE measured for a basic meter alone. Tapping temperature stays within spec, so quality is unchanged, and melts get shorter, so throughput can only rise. CO2 uses the CEA grid factor of 0.710; time-of-day savings are counted as money only.
